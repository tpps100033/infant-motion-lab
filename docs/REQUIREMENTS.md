# 計畫需求與平台對照

依使用者提供的《基於人工智慧的早期神經發育數位生物標記平台》計畫（2026-04-13 版本）建立。本次以第一年收案與分析平台為範圍；使用者指定 RTMPose，故不重新比較或替換成 MediaPipe。

| 計畫內容 | 對應功能 | 狀態與界線 |
|---|---|---|
| 0 至未滿 72 個月收案、監護人同意 | 研究代碼、收案月齡、週數、體重、同意日期與版本；IRB 資訊未確認時不能收案 | 可操作；倫理核准與書面同意由研究團隊辦理 |
| 一般發展、高風險、發展異常三組 | 入組分組與每次訪視分組快照 | 保留轉組歷程；不依 AI 自動診斷分組 |
| 每月追蹤 | 訪視日期、實足／校正月齡、下次訪視提示 | 可操作；校正方式見 METHODS |
| 每次至少連續 3 分鐘可用影片 | 可用秒數與拍攝品質檢核、審閱納入條件 | 短片可測試分析，但不會通過研究資料匯出審閱 |
| 手機自然活動拍攝 SOP | 全身、光線、固定相機、自然活動、語音內容檢查 | 面板內含 SOP；指引影片需由研究團隊依核准流程錄製 |
| 姿態估計與關節軌跡 | RTMPose-M、17 點、ROI、時間軸、原始座標與缺口標記 | 已完成瀏覽器推論；2D 投影 |
| 速度、變異度、平滑度、幅度、對稱性與協調性 | 關節 × 時間窗指標、速度／加速度曲線、協調性、肘膝角度、CSV | 本版新增擴充欄位與方法定義 |
| 嬰幼兒多模態資料庫 | SQLite 加密紀錄、AES-GCM 媒體庫、登入角色、操作稽核 | 私人 localhost 服務；不使用公開 GitHub 儲存個案資料 |
| 語音前處理與基礎聲學特徵 | 高通、能量端點候選、音高與節律描述、逐段來源標籤 | 可操作基礎版；聲源、哭聲與牙牙學語由人工確認，未宣稱自動辨識效度 |
| Bayley-III、GMA、MCDI 對齊 | 工具版本、施測日期、評估者代碼、分數與臨床判讀 | 登錄已完成量表的結果；不重製受授權限制的量表題本 |
| MCDI 每三個月施測 | 既有 MCDI 日期後推 3 個月提示 | 實際適用版本與年齡由評估人員確認 |
| 多次訪視與發展曲線 | 同一個案、同模型／參數／指標版本的已審閱結果趨勢 | 是個體趨勢；尚無族群月齡常模 |
| 第一／二年開發、第三年獨立驗證 | 收案年度、場域代碼、development / external 標記 | 匯出保留個案與 cohort，供後續以受試者分割資料 |
| 5–10 人初步可用性測試 | 測試者代碼、角色、10 題 SUS 答案與分數、質性回饋 | 可收集；不虛構已完成的測試人數 |
| 資料保存至計畫結束後最多五年 | 研究結束日、保存期限提示、退出、管理員清除流程 | 不自動刪除；備份副本須依同一核准保存程序處理 |
| 備份與轉移伺服器 | 加密備份下載、獨立金鑰、還原驗證 | 詳見 PRIVATE_SERVER |
| Random Forest / SVM / LSTM、多模態預測、ROC-AUC 等 | 資料與版本欄位供第二年建模使用 | 尚無訓練資料與驗證結果，不產生虛構風險分數 |

## 需由計畫主持人確認的文字差異

- 第 10 頁的第一年新增收案為 300 名（一般 ≥200、高風險約 80、發展異常約 20）。
- 第 13 頁工作項目寫 500 名，成果又寫 300 份可用資料。
- 面板預設採第 10 頁的 300 名，管理員可調整目標。研究報告須以最終 IRB 核准版本為準。

## 不應混用的比例

「關節判定率」為座標有效且通過分數門檻的比例；「軀幹有效率」為可建立軀幹座標的時間比例；「最低有效率」為特徵視窗品質條件。三者均不是人工關節真值準確率，也不是臨床診斷敏感度。
